# diligaf
This is a toy programming language to show how to write propper lexers, parsers, and interpreters in Lisp. This language could be a full functioning hacking programming language if someone ever wanted to take the time to work on it and implement a lot of the keywords however, that wasn't the intentions for creating it.
Although, if someone would like to do such, You are more than welcome to use this language as a baseline to streamline :D
